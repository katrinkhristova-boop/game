# Dragon Labyrinth Website - Image Setup Guide

## Overview
This website showcases an exciting dragon labyrinth game with interactive features and beautiful styling.

## Files Created
- `index.html` - Main website structure
- `style.css` - Complete styling and responsive design
- `script.js` - Interactive features and animations
- `README.md` - This file

## Image Files Needed
To complete the website, save the provided images with these exact filenames in the same directory:

1. **dragon.png** - The main dragon character image
   - Used in the hero section
   - Size: Recommended 400x400px or larger

2. **game-map.png** - The labyrinth/maze map with trees and treasure
   - Used in the game section
   - This is your game grid image

3. **up-arrow.png** - Up arrow control icon
   - Used in controls section
   - Size: Recommended 80x80px

4. **down-arrow.png** - Down arrow control icon
   - Used in controls section
   - Size: Recommended 80x80px

5. **left-arrow.png** - Left arrow control icon
   - Used in controls section
   - Size: Recommended 80x80px

6. **right-arrow.png** - Right arrow control icon
   - Used in controls section
   - Size: Recommended 80x80px

7. **tree.png** - Tree illustration
   - Used in resources section
   - Size: Recommended 100x100px

8. **food.png** - Food/fish/seafood items
   - Used in resources section
   - Size: Recommended 100x100px

## How to Use

1. **Save the images** in the same folder as the HTML, CSS, and JS files
2. **Open `index.html`** in your web browser
3. The website should display with all styling and images
